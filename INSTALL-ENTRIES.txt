The entry template, on Writing in Transit: starscapes-entries-19oct.zip   (no SQL)

WHAT IT BUILDS (from your Figma design "Archive Entry / Author's Notebook")
A page template for a series of entries, used right now on WRITING IN TRANSIT (Explorer's Bay, at /explorers-bay/writing-in-transit), replacing its plain list:
  * the LATEST ENTRY, big, on the left: its picture, a "Latest entry" chip, the date, the title, "Read the entry".
  * the PINNED ENTRY on the right: "Pinned", "Entry 1", its title, "Start from the beginning".
  * a GRID of the rest underneath the latest entry, newest first, up to eight (more open with "Show more entries").
  * On a PHONE it is one column: latest, pinned, the grid (four first, then "Show more entries").
The title, the line under it and the tag that picks the posts all still come from the room's own data, so they live in one place.

HOW YOU CHOOSE THINGS (the Tags box on a post; no database change, no change to your forms)
  * A post belongs on this page if it has the tag  writing-in-transit  (as before).
  * LATEST ENTRY: simply the newest post.
  * PINNED ENTRY: the newest post that also has the tag  pinned  . If none does, the OLDEST post is pinned: the beginning of the series ("Start from the beginning").
    A post is never shown twice: if the newest is the one tagged pinned, the oldest is pinned instead.

INSTALL (from the project folder, in this order; ONLY run git add . at the very end)
1. cd ~/Website/supabase-blog-starter
2. unzip -o ~/Downloads/starscapes-entries-19oct.zip
3. python3 tools/add-entry-template.py       (it checks the file first; if anything is unexpected it changes nothing)
4. node tools/health-check.mjs | tail -2      (all 156 checks should pass)
5. npm run build                              (must finish without errors)
6. git add .
   git status                                 (no files ending .before- should be listed)
   git commit -m "Entry template on Writing in Transit"
   git push
7. Wait for Vercel to say Ready, then hard-refresh (Cmd+Shift+R).

THEN LOOK, and SEND ME A SCREENSHOT (I cannot see the live page), at /explorers-bay/writing-in-transit
