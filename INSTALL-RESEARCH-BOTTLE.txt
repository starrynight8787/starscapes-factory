4. npm run build                             (must finish without errors)
5. git add .
   git status                                (no files ending .before- should be listed; the two old pictures should show as deleted or renamed)
   git commit -m "SFW-196 Research door; the bottle's own padlock"
   git push
6. Wait for Vercel to say Ready.
