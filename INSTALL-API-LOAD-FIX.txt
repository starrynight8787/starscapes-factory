URGENT FIX: /api/ebook-signup AND /api/membership-checkout CRASH ON LOADING ON VERCEL   starscapes-api-load-fix-23oct.zip   (SFW-261)
(No Supabase step. It does NOT touch NEWSLETTER_OPEN and does NOT open sign-ups.)

WHAT WAS WRONG
  Vercel runs the API functions in plain Node, which needs a file extension on every relative import. Four imports had none, so two functions crashed the moment they loaded (500 on every request):
    src/newsletter/newsletterRules.js    from '../data/company'            -> breaks /api/ebook-signup (and the Admin newsletter tools) since the newsletter was released
    src/membership/account.js            from './passes' and './pricing'   -> breaks /api/membership-checkout (passes, members, promotions, newsletter admin, story rounds, the daily renewal reminders)
    src/admin/promotionsRules.js         from '../membership/pricing'       -> the same function
  The tests never saw it because they run through Vite, which accepts imports without an extension. THE FIX adds ".js" to those four imports (3 files).

WHEN IT STARTED (checked commit by commit, with plain Node, and matched to Vercel's production deployments)
  * /api/membership-checkout: from the production deployment of commit 5f28a32 "Admin: build the Passes and members page", dpl_J65Z5JzzPhSfe5VpfYn342G4wQ7a, Tuesday 20 October 2026, 21:53 UTC (22:53 UK time). The deployment before it was fine.
  * /api/ebook-signup: from the production deployment of commit c05b8aa "Admin: build the newsletter", dpl_8CSJ7ubQLFdBrU9ewN3Gw4oXaW7N, Tuesday 20 October 2026, 22:45 UTC (23:45 UK time). The deployment before it (1fecdd5) loaded fine.
  Every production deployment since has had both problems. The other 10 functions load fine and were never affected.
  What failing meant: the sign-up forms ask "is it open?" and treat a failed answer as "no", so they showed "Sign-ups are not open just yet" and the footer box stayed hidden. It looked like "closed", not like an error. The two daily jobs
  (renewal reminders at 08:00 and the clean-up of unconfirmed sign-ups at 08:30) have been failing since the same times; neither had anything to do yet.

THE TEST (so this can never pass the suite again): test/api-loads-like-vercel.test.js, 16 tests. It loads EVERY file in api/ in a fresh plain Node process (no Vite), exactly as Vercel does, and fails if any cannot be loaded or exports nothing that can answer a request;
  it scans every file the API functions can reach for an import without an extension and names it; it calls the "is it open?" answer the way Vercel does and checks it follows NEWSLETTER_OPEN being exactly "yes" (not "Yes", not "true"); and it checks each scheduled job points at a real function.
  10 DELIBERATE BREAKAGES, ALL CAUGHT, including the original bug put back.
