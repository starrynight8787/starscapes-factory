The Book Club page: starscapes-book-club-19oct.zip   (NO Supabase step, nothing to do in Stripe or Vercel)

WHAT IT DOES
Rebuilds the Book Club page to your new design (Figma: "Book Club v3"), on top of the books, reading goals, suggest-and-vote box and reviews you already have:
   * a banner with the "Members" chip
   * a WELCOME card (a video, or "Welcome video coming soon" until you add one) beside the MEMBERSHIP card ("Into the Nebula", with a Coming soon chip and a button that does nothing until memberships open; once
     you set open to true in src/data/membership.js it becomes "Choose your passes", linking to /membership)
   * This year's theme (with "Join the conversation"), the COME READ card ("Read along with me", with the "Come read with me" button to your live sessions), Reading now, Up next (with the suggest-and-vote box),
     and THE SHELF: a tile for each year (oldest first, with how many books), and a dashed empty tile for the year to come
   * the genres drawn as five BOOKS ON A BOOKSHELF (each one links to the notes with that tag); on a phone they lie flat in a pile so the names stay readable
   * the chosen year's shelf of spines, goal bar and book card (it was the old "The shelf" section) now sits under the genres and follows whichever year tile you press
   * Reviews and conversations, full width (the pass labels appear on these cards too, once the pass labels package is installed)
On a phone the cards come in the order of your phone design.

WORDS YOU CAN CHANGE (src/bookclub/bookClubData.js; they are my placeholders in your voice):
   WELCOME.title and WELCOME.text      the message in the welcome card
   WELCOME.videoId                     paste the 11 characters after v= in a YouTube address (for example abc123DEF45) and the card becomes a video. It only loads from YouTube when it is pressed.
   MEMBER_BENEFITS                     the three lines in the membership card
   COME_READ.note                      the line in the Come Read card (this is also in the Figma design, which I will match)
Nothing else changes: the books and goals tool in Admin works exactly as before.

INSTALL (from the project folder; ONLY run git add . at the very end)
 1. cd ~/Website/supabase-blog-starter
 2. unzip -o ~/Downloads/starscapes-book-club-19oct.zip
    (this also replaces one older test file with an updated version)
 3. python3 tools/add-book-club-v3.py         (it checks the three files first; if anything is unexpected it changes nothing)
 4. node tools/health-check.mjs | tail -2     (every check should pass)
 5. npm run build                             (must finish without errors)
 6. ls api/*.js | wc -l                       (it should still print 12)
 7. git add .
    git status                                (no files ending .before- should be listed)
    git commit -m "Book Club: the new design"
    git push
 8. Watch Vercel's Deployments page for READY. If it says Error, click it and send me the words. Do not redeploy by hand.

HOW TO SEE IT (after it is Ready): open the Knowledge Nook, then the Book Club door (it is the door you opened for yourself): starscapesfactory.com/knowledge-nook/book-club
 Check on your phone too. Press a year tile (for example 2025): the shelf below the genres should change to that year.
