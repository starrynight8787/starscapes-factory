ART LOFT: READY FOR PINTEREST   starscapes-pinterest-ready-24oct.zip   (the brief of 24 October 2026; shop opens 15 November)

WHAT THIS DOES (each item below is checked by tests, and each test was proved by deliberately breaking the thing it protects: 32 breakages, all caught)
 1. PRODUCT MARKUP on every print page, in the page's own HTML (Pinterest's crawler does not run the site's code): og:type "product", product:price:amount, product:price:currency (GBP),
    og:availability (instock) AND Schema.org Product JSON-LD (name, url, image, description, sku, brand, offers with price, priceCurrency, availability). The price is the print's LOWEST price
    ("from"), read from its own sizes and frames. A print with no readable price or no real picture gets NO product markup (a wrong price in a pin is worse than none).
 2. LINK-PREVIEW PICTURE SIZE: the real size of each print photo is read when the site is built, and that size is stated. If a photo cannot be measured, NO size is stated (it never says 1200 x 630 by
    default again). The ten shared room pictures really are 1200 x 630, and a test checks each real file.
 3. SITEMAP: the code was already right (see "WHAT YOU MUST DECIDE" below). It lists the home page, the Art Loft pages, every collection and every PUBLISHED print (by its readable address), and leaves out drafts,
    admin pages and anything marked noindex. Tests prove this by running the real build. It is EMPTY today only because the whole site is deliberately closed to search engines.
 4. READABLE ADDRESSES: /art-loft/prints/behind-the-curtain. Set once (sql/print-slugs.sql), LOCKED once set (the database refuses a change), given automatically to every print added later. The old long
    addresses go to the readable ones with a PERMANENT redirect (tools/make-print-redirects.mjs writes them into vercel.json). Originals are skipped for now, as the brief allows.
 5. TITLES AND DESCRIPTIONS, specific to each print, e.g.
      Behind the Curtain: abstract acrylic art print | Starscapes Factory
      Behind the Curtain: an abstract acrylic art print from the Out of this World collection, digitised from my original painting. Framed in black or unframed, in 4 sizes (21 x 30 cm, 28 x 35 cm, 40 x 50 cm and 60 x 80 cm), made to order.
    Built from each print's own name, collection, frame colour and sizes.
 6. THE MEDIUM LINE on every print page: "Digitised from my original acrylic painting, printed to order." (after the collection, before the description). The originals' pages and cards are not touched.
 7. ALT TEXT on the print cards ("Behind the Curtain, abstract art print, Out of this World collection") and on the collection pictures; and THE HEADING on /art-loft: white on near-white on a phone or small tablet
    (1.06 to 1) now dark ink (16.9 to 1), with no change to the layout or to the desktop.
 8. PINTEREST CLAIM TAG: ready and waiting. Nothing is added until you paste Pinterest's code into PINTEREST_VERIFY in src/data/siteSettings.js (see "LATER").
 9. CHECKS (reported to you in the chat): robots.txt (only admin and API paths blocked), no custom firewall rules or bot protection, no attack mode, your public domain is not password-protected.
