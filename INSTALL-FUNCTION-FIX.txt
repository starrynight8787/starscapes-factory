WHAT WENT WRONG
Vercel's free plan allows only 12 "serverless functions" per site, and every file in the api folder counts as one. You had exactly 12. The account update added a 13th (api/membership-account.js), so
Vercel refused to build the site, every time, in about ten seconds. While that happens Vercel keeps serving the LAST version that did build (the payment step), which is why your site stayed up.
This also explains the signing-secret trouble: you added the variable AFTER that last good build, and every "Redeploy" you pressed was of a FAILED build, so nothing ever picked it up.

THE FIX
The account actions (the card line, Stripe's billing page, taking back a cancellation, changing passes) now live in lib/membershipAccount.js, and the one membership function (api/membership-checkout.js) hands
those requests over. Nothing you see changes. There are 12 functions again. A new test fails loudly if anyone ever adds a 13th, so this cannot happen again.
The script also REMOVES api/membership-account.js, but only if it is exactly the file I put there (if you have changed it, it stops and says so, and changes nothing).
